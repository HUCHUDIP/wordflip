# Wordflip

앞면·뒷면 카드와 철자 시험을 사용하는 HTML 단어장 시제품입니다.

## 실행

- `index.html`을 열어 사용할 수 있습니다. 브라우저에서 파일 주소의 저장 범위는 환경마다 다르므로 JSON 백업을 주기적으로 내려받으세요.
- PWA 설치와 오프라인 캐시는 HTTPS 또는 localhost에서 제공합니다. 단순한 홈 화면 아이콘은 Android 1×1 위젯과 다릅니다.
- `wordflip.html` 단일 파일 버전은 별도로 제공됩니다.

## 제공 기능

- 여러 단어장, 자유로운 앞면·뒷면 문장, 카드 수정·휴지통 복원·즐겨찾기
- 앞면 학습, 뒷면 학습, 철자 시험의 독립 FSRS-6 상태와 복습 일정
- New / Learning / Relearning / Review 상태를 처음 / 잘 모름 / 복습 단계로 표시
- 철자 비교에서 대소문자와 공백만 무시. 맞히면 Good, 틀리면 Again
- 오늘의 학습과 복습 일정에 영향이 없는 집중 연습
- CSV, XLSX의 앞면·뒷면 첫 두 열 및 `앞면$뒷면` 형식의 TXT 가져오기
- CSV·XLSX 카드 내보내기, 전체 JSON 백업·복원, 기존 `wordflip_words` 데이터 이전
- 기기 음성 합성으로 앞면 자동·버튼 발음, 수동 IPA 기입과 사전 검색 링크

## 현재 구현 범위

Google 계정 자동 동기화에는 운영할 HTTPS 앱의 OAuth 설정과 충돌 병합 설계가 필요합니다. 이 파일은 기기 내 저장과 JSON 백업·복원을 제공합니다.

발음 기호는 네이버 사전을 링크로 열어 확인한 뒤 카드에 입력합니다. 사전 데이터의 자동 수집은 포함하지 않습니다.

이 PWA의 홈 화면 아이콘은 실행 바로가기입니다. Android 1×1 위젯과 APK는 별도 네이티브 프로젝트와 빌드가 필요합니다.

XLSX 처리는 JSZip 3.10.1을 포함합니다. JSZip 라이선스는 `jszip.min.js` 파일 머리에 있습니다.
